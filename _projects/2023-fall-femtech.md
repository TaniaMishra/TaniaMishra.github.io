* Investigated the effect of the Dobbs v. Jackson decision on data privacy in FemTech apps, focusing on user perspectives through app reviews
* Wrote Python scripts to scrape reviews using the SerpAPI and perform sentiment analysis using a machine-learning model from Hugging Face
* Conducted topic modeling using WordStat
